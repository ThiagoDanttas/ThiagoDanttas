## Sobre

Desenvolvedor **Python** com foco em automação de processos, integração de sistemas e aplicação de **LLMs e agentes de IA** em problemas reais de negócio.

Comecei em dados — dashboards, ETL, tratamento de bases de múltiplas fontes — e trouxe essa bagagem para o desenvolvimento. Na prática, isso significa que eu não construo só o pipeline: entendo o dado que entra, o indicador que sai e a decisão que ele sustenta.

- 🐍 Back-end em **Python** (FastAPI / Flask), integrações via **APIs REST**
- 🤖 **OCR + LLM** para extração estruturada de documentos e classificação automática

## O que eu construo

### 🚢 Pipeline de IA para conferência documental de cargas internacionais
Extração de campos estruturados de documentos de embarque marítimo (HBL/MBL) via **OCR + LLM**, com motor de pareamento por shipment, normalização de unidades e retorno automático de relatório de divergências à API do cliente. Substituiu a conferência manual e reduziu o risco de divergências não detectadas.

`Python` · `Claude API` · `OpenAI API` · `OCR` · `REST APIs`

### 📄 Automação de preenchimento de conhecimentos de carga (BL)
Pipeline *end-to-end* que lê e-mails via **Microsoft Graph API**, extrai dados de PDFs por OCR e preenche automaticamente os conhecimentos de carga no CargoWise. Inclui classificador de documentos e extração estruturada com **fallback automático** entre provedores de LLM, gerando XML de integração validado por tipo de documento.

`Python` · `Claude API` · `OpenAI API` · `scikit-learn` · `Microsoft Graph` · `OCR`

### 🔎 Automação de extração e consolidação de dados
Web scraping periódico de dados públicos com consolidação automática em banco relacional e pipeline de ETL que eliminou o tratamento manual de planilhas, padronizando a entrada de dados para relatórios.

`Python` · `Pandas` · `BeautifulSoup` · `SQL`
